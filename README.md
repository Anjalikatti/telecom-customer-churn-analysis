# Telecom Customer Churn Analysis 📊

## 📌 Project Overview
Customer churn is a critical challenge for telecom companies. This project focuses on analyzing customer churn patterns to identify key factors influencing customer retention and churn behavior using SQL and Power BI.

The analysis provides actionable insights into customer demographics, contract types, services, payment methods, and tenure to support data-driven decision-making.

## 🎯 Objectives
- Analyze customer churn trends and patterns
- Identify high-risk customer segments
- Understand the impact of contracts, services, and tenure on churn
- Create an interactive dashboard for business insights

## 🛠 Tools & Technologies
- **SQL Server** – Data cleaning, transformation, and analysis
- **Power BI** – Interactive dashboards & visualization
- **Excel / CSV** – Data source

## 🔄 Project Workflow
1. Imported raw telecom customer data
2. Cleaned and transformed data using SQL queries
3. Created calculated KPIs such as:
   - Total Customers
   - New Joiners
   - Total Churn
   - Churn Rate
4. Built an interactive Power BI dashboard with slicers and filters
5. Analyzed churn across multiple business dimensions

## 📊 Key Dashboard Features
- KPI cards for quick performance tracking
- Churn analysis by:
  - Gender & Age Group
  - State
  - Contract Type
  - Internet Type
  - Payment Method
  - Tenure Group
  - Services subscribed
- Drill-down and filtering for detailed insights

## 🔍 Key Insights
- **Month-to-month contracts** show the highest churn rate (~46%)
- Customers with **low tenure (< 6 months)** are more likely to churn
- **Fiber optic internet users** have higher churn compared to DSL
- Competitor-related reasons contribute most to customer churn
- Long-term contracts significantly reduce churn probability
